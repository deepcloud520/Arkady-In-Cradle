## Profile
《Arkady in Cradle》 is a sci-fi visual novel set in a fractured near‑future world, blending real‑time tactical wargaming with data‑link warfare and fog‑of‑war mechanics. You play as *Arcadia*, a newly EU commander，interacting with self‑aware strategic AIs, corporate militaries, and splintered nations in the year 2060. Every tactical decision ripples through the narrative.
