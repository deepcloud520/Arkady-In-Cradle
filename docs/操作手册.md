# 《Arkady in Cradle》操作手册

> 适用版本：Phase 6c（编队 AI / 炮兵 / 反炮 / RWR / 通信簇 / 诱饵已接入）
> 本文档面向玩家：如何启动、如何下指令、如何看懂战场。

## 一、启动与运行

### 1.1 初始化环境

```bash
uv sync                # 安装依赖（已配清华镜像）
uv sync --extra dev    # 含 pytest / matplotlib 等开发依赖
```

### 1.2 运行主程序

```bash
uv run python main.py
```

- 主窗口左侧为**战场渲染**（2.5D 地形 + 单位 + HUD 标记），右侧为**侧栏**（对话/档案/简报/详情）。
- 若启动缓慢，多为首次 Numba 编译（一次性），稍候即可。

### 1.3 无头运行（战役自动化）

```bash
uv run python -m tests.benchmark_phase6      # Phase 6c 性能基准
uv run python -m tests.benchmark_collision   # Phase 3 碰撞/开火链基准
```

## 二、基本操作

### 2.1 摄像机

| 操作 | 效果 |
|------|------|
| 左键拖拽 | 旋转视角（轨道） |
| 滚轮 | 缩放 |
| 右键/中键拖拽 | 平移 |

摄像机可钻入桥下、拉到高空战略视图，与逻辑层零耦合。

### 2.2 键盘快捷键

| 键 | 功能 |
|----|------|
| `空格` | 暂停 / 恢复 |
| `回车` | 推进对话 / 叙事 |
| `1`–`9` | 选择对话选项 |
| `S` | 跳过战斗（模拟仍在后台运行，叙事层消费结果） |
| `Ctrl+1/2/3` | 切换渲染主题（default / constructivism / anime） |
| `F1` | 帮助 |
| `Esc` | 取消当前选中 |

### 2.3 选中与详情

- 鼠标单击单位 → 选中（HUD 高亮大圆）。
- 右侧「详情」面板按**三级信息**展开：编队概览 → 单位状态 → 部位/弹药明细。

## 三、下达作战指令

玩家指令统一走 `CommandQueue`（叙事层唯一入口，AGENTS.md 3.7），模拟层每 Tick 消费：

| 指令 | 语义 |
|------|------|
| `STRIKE` | 呼叫支援打击（炮兵曲射 / 未来巡飞弹·CAS）。参数 `coords`（世界坐标）或 `target_idx`（活目标） |
| `REDEPLOY` | 兵力再部署 |
| `HOLD` | 待命 / 静默（辐射管制） |

> **玩家指令优先级最高**：玩家 `STRIKE` 覆盖编队 AI 的自主决策（docs §六.2）。

## 四、看懂战场

### 4.1 HUD 标记

- **单位文字标签**（字体图集）：单位名 / 阵营。
- **弹道线**：直射/曲射弹丸轨迹。
- **命中标记**：渐隐的命中点。
- **损坏 ⚠ 摘要**：受损单位警告。

### 4.2 战争迷雾（通信簇）

- **大面板可见** = 处于**中央集群**（`comm ≥ 0.5`）的己方编队——你能看到其部署与行动。
- **失联编队**（`comm < 0.5`）→ **独立建网**，照常自主协同，但大面板**不可见在干什么**。

### 4.3 事件日志

左下角滚动日志记录：开火 / 命中 / 摧毁 / 反炮 / RWR 告警 / 疏散 等内循环事件。

## 五、故障排查

| 现象 | 处理 |
|------|------|
| 渲染全黑 | Qt FBO 上下文丢失 → 重开窗口（或等待 `detect_framebuffer()` 强制重绑） |
| 主题切换后地形变黑 | 菜单槽 GL context 非 current；重切一次主题 |
| 首次启动慢 | Numba 首次编译；改过 Numba 核后先 `uv run python clear_numba_cache.py -y` |
| 测试失败提示权限 | 沙箱临时目录限制，用 `-p no:cacheprovider` 运行 pytest |
