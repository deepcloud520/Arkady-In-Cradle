## 0. 结论速览

| 问题 | 结论 |
|---|---|
| 曲率烘在哪？ | **A 方案**：`spans` 保持平面；WM 建顶点时套 `z − d²/(2R)` |
| 谁做检测？ | **全部走 WM**：LOS / 雷达 / 激光指示 / 数据链；`spans` 只给地形破坏 |
| 坐标怎么存？ | **`LocalFrame`**：`(frame_id, x, y, z)` float32；ECEF 只做换算，不落库 |
| 结构怎么做？ | **真 3D**：CSG/参数化 → 局部体素（精度随 chunk）→ Dual Contouring → 三角网 |
| 结构能破坏吗？ | 能：挖体素 + 局部重网格 + 双缓冲（整块移除为降级方案） |
| 斜面/拱/斜屋顶？ | 支持；不再受 `span` 轴对齐限制 |
| 多视图？ | 一份场景 + 每视图一个 FBO；正交俯视 / 透视自由切 |
| 弹道？ | WM 高度进入火控 + 径向重力 + 科氏力 |
| 现在要不要 ECEF/八叉树/整颗地球？ | **不要**，只留接口 |

**曲率数值（R = 6 371 000 m，中心锚点）**

| 水平距离 | 下坠 `d²/(2R)` | 铅垂线倾角 `atan(d/R)` |
|---|---|---|
| 10 km | 7.9 m | 0.09° |
| 40 km | 125.6 m | 0.36° |
| 47 km（80×50 对角半径） | 173.3 m | 0.42° |
| 60 km | 282.5 m | 0.54° |
| 80 km | 502.3 m | 0.72° |
| 100 km | 784.9 m | 0.90° |
| 400 km | 12.56 km | 3.59° |
| 566 km（800×800 角落） | 25.1 km | 5.08° |

> 经验门槛：`d²/(2R) ≤ 1 km` 且 `atan(d/R) ≤ 1°` → **d ≈ 110 km**。
> 单锚点适用 ≤ 100 km；800 km 级必须分块（每块 100 km）。

## 2. 坐标系统

### 2.1 LocalFrame（唯一存储坐标）

```python
@dataclass(frozen=True)
class LocalFrame:
    frame_id: int
    lat0: float          # 锚点纬度（°）
    lon0: float          # 锚点经度（°）
    alt0: float          # 锚点正高（m）
    x0: float = 0.0      # 锚点在地图坐标中的 x（锚点为原点时恒 0）
    y0: float = 0.0      # 锚点在地图坐标中的 y（锚点为原点时恒 0）
    heading: float = 0.0 # 局部 +X 相对正东的旋转（°，可选）
```

- 单位坐标：`(frame_id, x, y, z)`，`float32`，单位米；
- 锚点用经纬高存（全球身份），单位用本地米存（可计算坐标）；
- 精度：`float32` 在 100 km 处约 **8 mm**，800 km 处约 **6 cm**。

### 2.2 ECEF 的定位

**只做换算，不做存储。**

| 用途 | 是否用 ECEF |
|---|---|
| 单位/弹丸位置存储 | ❌ |
| 跨帧查询（导弹跨块、跨图接缝） | ✅ 临时换算 |
| 海图解析球面 | ✅（或直接用球面公式） |
| 锚点元数据 | ❌（用经纬高） |

理由：`float32` 在 6371 km 量级最小间隔约 **0.5 m**，不够给地面单位用；`float64` 精度够但热路径带宽翻倍。

### 2.3 两个 z 的命名纪律（强制）

| 名称 | 含义 | 使用者 |
|---|---|---|
| `z_span` | 平面高度（`spans` 层高） | 仅地形破坏 |
| `z_wm` | 弯曲后的世界高度 | 检测、移动、渲染、火控 |

换算只有一个入口：

```python
z_span = z_wm + drop(x, y)      # 破坏 API 内做
z_wm   = z_span - drop(x, y)    # WM 建顶点时做
```

**禁止**任何几何查询读 `heightfield.surface_z()` / `continuous_ground`（红线 2）。

## 3. 曲率方案（A：spans 平面 + WM 弯曲）

### 3.1 变换

```python
R_EARTH = 6_371_000.0

def drop(x, y, frame):          # 相对锚点的下坠（m）
    dx, dy = x - frame.x0, y - frame.y0
    return (dx * dx + dy * dy) / (2.0 * R_EARTH)

def wm_vertex_z(z_span, x, y, frame):
    return z_span - drop(x, y, frame)
```

- 抛物近似误差 `d⁴/(24R³)`：80 km 处约 6.6 mm，100 km 处约 16 mm，可忽略；
- x/y 不做横向收缩（真球面投影在 80 km 处差约 2 m，不值得付复杂度）。

### 3.2 为什么在 WM 建时弯，而不是改 spans

| | A：spans 平面（选定） | B：spans 烘弯 |
|---|---|---|
| 存储 | 不变 | 不变，但 `z_min` 要下移 |
| 破坏 | 平面 z，简单 | 弯 z，坐标语义变化 |
| 检测 | 必须全走 WM | 走 spans/WM 都一致 |
| 重建 | 每顶点一次减法 | 无额外计算 |
| 曲率调参 | 重建 WM 即可 | 不可逆，需重生成 |
| 真理数 | 两个 z（靠命名纪律） | 一个 z |

选 A：曲率是**视图参数**，破坏仍在线性平面空间里；符合“spans 只管破坏、WM 管几何”的分工。

### 3.3 锚点

- 单块：放块中心/重心（80×50 最远角 47 km → 173 m）；
- 多块：每 100 km 一块，块内最远角 ~70.7 km → 393 m；
- 锚点不要求“正中心”，但**最远角下坠要写进文档与测试**。

### 3.4 海拔显示

```python
altitude_msl = z_wm + drop(x, y)    # 仅 UI / 简报 / 详情面板
```

仿真内部一律用 `z_wm`，不做 MSL 换算。

## 4. 数据布局

### 4.1 地形（不变）

`Heightfield`：列式 span，`(N_COLS, MAX_SPANS, 4)` uint16 + `count` uint8，约 **65 B/列**；
**曲率不写入**，`z_min`/`ch` 保持现状。

### 4.2 WorldMesh（弯曲视图）

- 地面：逐格四边形（`DualContourBuilder` 现状），顶点 z = `spans` 双线性 `− drop`；
- 结构：真 3D 三角网（见 §5），顶点同样 `− drop`；
- 每个 patch 增加：

```python
structure_id: int = -1     # -1 = 地形；≥0 = 结构实例
walkable: bool
```

- 地面 patch 的 `mesh_id` 契约不变（`locate_patch → z_at`）。

### 4.3 变精度（作者指定）

```
基础网格（铺满 800×100，cell 200~400 m，ch 1.0）
  + 高精度块列表（10~20 km，cell 2~5 m，ch 0.25）
```

- 定位：`zone_grid[gx, gy]` 一字节查“这里有没有精细块”，O(1)；
- 查询：点在精细块内 → 该块局部网格；否则基础网格；
- **暂不上四叉树**（作者指定 + 两级已经够），出现第三、四级再换。

### 4.4 内存预算

| 区域 | 参数 | 列数 | span 内存 |
|---|---|---|---|
| 80×50 基础 | 40 m | 250 万 | ~163 MB |
| 80×50 基础 | 20 m | 1000 万 | ~650 MB |
| 800×100 基础 | 200 m | 200 万 | ~130 MB |
| 800×100 基础 | 400 m | 50 万 | ~33 MB |
| 高精度块 5×5 | 5 m | 100 万 | ~65 MB |

结论：**基础图粗网格 + 少量高精度块，总预算 300~500 MB**。

## 5. 结构管线（真 3D）

```
形状 DSL（CSG / 参数化）
   → 局部体素（精度随 chunk）
   → Dual Contouring（QEF）
   → 三角网（材质 / walkable / destructible）
   → 施加曲率（− drop）
   → 进 WorldMesh
```

### 5.1 形状来源（不导入模型）

| 形状 | 定义方式 |
|---|---|
| 斜桥面 | 楔形/拉伸体 |
| 斜屋顶 | 三棱柱 / 放样 |
| 斜拱 | 路径扫掠（拱线 × 截面） |
| 隧道 / 涵洞 | 布尔挖除 |
| 通用 | CSG 并/交/差 |

### 5.2 体素

- **只建局部体**：结构包围盒外扩 1~2 格，用完即丢；
- 体素尺寸 = 所在 chunk 的精度：精细块 0.25 m，基础区 0.5~1 m；
- 体素场存 `float32` SDF（内部负、外部正），DC 用其梯度/边交点。

### 5.3 Dual Contouring 要点

1. 每格用 QEF 求顶点；尖锐特征用**法线约束**（否则桥缘、屋脊会被磨圆）；
2. 跨格连面，输出三角形（不用四边形，方便 BVH/渲染统一）；
3. 处理非流形与退化 QEF（加正则项，回退格中心）；
4. 顶点法线 = SDF 梯度，供渲染与悬挂。

> 风险最高的一块。先用楔形/棱柱做通管线，再替换成通用 DC。

### 5.4 可走性

- `walkable = 坡度 < 阈值 且 面积 ≥ 阈值`；
- 相邻结构面片按共享边建邻接；坡道与桥面按 `max_climb` 放宽；
- 单位 `z_at` 走 `WorldPatch` 平面/双线性，斜面天然支持。

## 6. 破坏

### 6.1 地形

`Heightfield.remove_span(x, y, z_span, ...)`；**唯一写入口**，改完标脏。

### 6.2 结构

```
爆炸 → 定位结构 chunk → 在局部体素框内挖球/柱
     → 标脏 → 后台局部 DC 重网格
     → 新三角网 + BVH 就绪 → Tick 间隙原子替换
```

- **双缓冲**：重网格期间旧 chunk 继续服务 LOS/渲染；
- 破坏粒度 = 体素；整块移除作为降级路径（性能/资产不足时）；
- 跨 chunk 的结构必须按 chunk 切分，边界共用体素，避免缝。

### 6.3 地形 + 结构的交叠

桥墩、建筑与地形重叠时：地形 span 与结构体素各自独立；查询时取**最近命中**（§7）。

## 7. 检测（统一走 WM）

### 7.1 `world_raycast`

```python
def world_raycast(o, d, max_t, chunks, struct_bvh) -> Hit | None:
    # 1) 地面：按 chunk 分辨率做 2D DDA，逐格比较双线性 z
    # 2) 结构：BVH 射线查询（Möller–Trumbore）
    # 3) 返回最近命中（t, patch_id / structure_id, normal, mat）
```

- 输入输出全是 `z_wm` 世界坐标；
- 地面走逐格（O(1) 查表，和现有 DDA 同量级），结构走 BVH（稀疏）；
- 不需要跨 chunk 统一 `cs`：**按 chunk 边界裁剪射线**，每段用该 chunk 的 `cs/ch`。

### 7.2 消费者清单

| 消费者 | 现状 | 改后 |
|---|---|---|
| `combat/engagement.py` 交战 LOS | `line_of_sight`（spans） | `world_raycast` |
| `combat/sal.py` 激光指示 | `line_of_sight` | 同上 |
| `simulation/air_ai.py` 机载雷达 | `LosChecker`（spans） | 同上（地平线由几何涌现） |
| `simulation/datalink.py` 链路 | `LosChecker` | 同上 |
| 弹道触地 / 落点 | `hf` 采样 | WM 查询 |

旧 `detection/los.py` 保留为 fallback 与对拍基准。

### 7.3 雷达地平线

- 几何地平线由 WM 射线自然产生；
- 大气折射（4/3 地球）仍可作为**可选预筛**：`R_h = √(2kR·h₁) + √(2kR·h₂)`，`k = 4/3`；
- 预筛只减调用，不替代射线。

## 8. 弹道

### 8.1 火控

- 炮口/目标高度取 `z_wm`（曲率已自动进入 `z0`）；
- 解析解 `solve_ballistic` 仍作初值，再用“打-修”迭代收敛（科氏/径向重力无解析闭式）。

### 8.2 积分器

```python
C = frame.earth_center()                 # 锚点下方 R
g_vec = -G * (p - C) / norm(p - C)       # 径向重力

Omega = frame.omega_vector()             # ENU: (0, Ω cosφ, Ω sinφ)
a_cor = -2.0 * cross(Omega, v)           # 科氏
```

只改**弹丸积分**（`integrate_projectile_movement` / 制导版）；地面与空中单位不动。

### 8.3 量级（粗算，800 m/s 级火箭）

| 修正项 | 40 km（~50 s） | 80 km（~100 s） |
|---|---|---|
| 曲率（端点高度差） | ~126 m | ~502 m |
| 径向重力 | ~25 m | ~200 m |
| 科氏力 | ~100 m | ~400 m |

验收：80 km 火箭落点误差 **< 5 m**（对照 ECEF 参考积分）。

### 8.4 何时可以省

- 直射 ≤ 8 km：曲率 < 5 m、科氏 < 1 m，可继续用现有模型；
- 80×50 图内最远 47 km：建议直接全开，成本可忽略。

## 9. 渲染与多视图

### 9.1 视图架构

```
一份场景数据（WM / 纹理 / LOD）
   ├─ View 0：正交俯视，中心 A
   ├─ View 1：正交俯视，中心 B
   └─ View 2：透视，看 C
```

- 每个视图：自己的相机、投影、视口矩形、FBO；
- 共享：WM、纹理、LOD、拾取索引；
- 实现：**隐藏 GL 上下文 + 每视图 FBO**，再贴到任意布局（分屏 / 浮动 / Tab）；
- 拾取：每视图按自己的相机反投影。

### 9.2 相机

| 模式 | 用途 | 要点 |
|---|---|---|
| 正交（ORTHO） | 战术俯视，像 2D 地图 | `zoom` = 屏幕宽度对应米数；z 不参与投影，看不到曲率 |
| 透视（PERSP） | 战略态势 | 拉远可见地平线弧度 |

- 需要 pan（中键/右键拖拽），速度 ∝ `distance`；
- `near = clamp(distance × 0.01, 1, 500)`；`far = max(3 × 对角线, distance + 对角线)`；
- 俯视图保持“平面感”，曲率只在透视高空出现。

## 10. 实施阶段与验收

| 阶段 | 内容 | 验收 |
|---|---|---|
| **P0** | `LocalFrame` + WM 建时压弯 + 单测 | `wm_z − z_span == drop(x,y)`；80 km 处 502.3 m |
| **P1** | `world_raycast`（地面 DDA + 结构 BVH）+ 对拍 | 1000 条随机射线与旧 DDA 一致率 ≥ 99.9%，耗时 ≤ 现状 1.2× |
| **P2** | 结构管线：楔 → 体素 → DC → WM | 30° 斜桥可渲染、挡视线、`z_at` 正确 |
| **P3** | 破坏：挖体素 + 局部重网格 + 双缓冲；消费者切 WM | 炸断桥段后 LOS 立即开通，主线程无卡顿 |
| **P4** | 径向重力 + 科氏 + 火控迭代 | 80 km 火箭落点误差 < 5 m |
| **P5** | 多视图 FBO + 正交相机 + pan | 两俯视 + 一 3D 同屏 60 fps |

预估：P0 半天；P1 2~3 天；P2 4~6 天（DC 是主体）；P3 3~5 天；P4 1~2 天；P5 2~3 天。

## 11. 风险与守护条款

| # | 风险 | 守护 |
|---|---|---|
| 1 | 真 DC 的 QEF/非流形 | 先楔形通管线；QEF 加正则项；退化回退格中心 |
| 2 | 局部重网格延迟 | 双缓冲；重网格期间旧 chunk 继续服务；预算 < 1 帧 |
| 3 | `z_span` / `z_wm` 混用 | 命名强制 + 单测（任一几何消费者读 spans 即失败） |
| 4 | BVH 构建/内存 | 只覆盖结构；按 chunk 建树；空 chunk 不建 |
| 5 | 跨 chunk 结构缝 | 结构按 chunk 切分，边界共用体素 |
| 6 | 摘除 `continuous_ground` 后地面变糙 | 地面 z 改 `spans` 双线性；必要时精细块 `ch=0.25` |
| 7 | 射线跨不同 `cs` 出错 | 按 chunk 裁剪射线，逐段用本块 `cs/ch` |

## 12. 非目标（本轮不做）

- ECEF 作为存储坐标；
- 八叉树 / 全局 3D 体素；
- 整颗地球（cube-sphere / geodesic）；
- 800×100、800×800 的生产化（只留 provider 接口）；
- 外部模型导入（结构全程序化生成）；
- 结构“预切碎块”破坏（先做体素挖除）；
- 让 `continuous_ground` 进入世界模型查询链（红线 2）。

## 13. 假设（如变更需评审）

1. 曲率采用 **A 方案**（`spans` 平面 + WM 弯）；
2. 基础网格 `ch = 1.0`，高精度块 `ch = 0.25`；
3. 多视图采用 **FBO + 任意布局**，不是共享上下文的多个 `QOpenGLWidget`；
4. 结构体素默认 **0.25 m（精细块）/ 0.5 m（基础区）**；
5. 旧 `line_of_sight` 保留为 fallback 与测试基准，不删除。
