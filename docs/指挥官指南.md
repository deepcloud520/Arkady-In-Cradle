# 《Arkady in Cradle》指挥官指南

> 适用版本：Phase 6c（编队指挥链 AI 完整闭环）
> 本文档面向指挥官：如何理解并运用编队 AI、炮兵、电子战与通信体系。

## 一、指挥哲学：编队决策，单位执行

- **编队 AI 是大脑**：持有意图 FSM、汇总敌接触、分配打击任务，通过指挥链
  （写成员 `order`/`target_idx`）下达指令。
- **单位 AI 是手脚**：只执行（开火 / 机动 / 固守），不做独立决策。
- **AI 只决策不执行**：一切行动走既有接口（`FiringControl.fire` / `ArmorPool.wp` /
  `CommandQueue`），绝不直接改 SoA 数组。

### 编队意图 FSM

```
MANEUVER（机动）→ 遭遇敌 + 兵力优势 → ADVANCE（进攻）
              → 遭遇敌 + 兵力劣势 → DEFEND（防御）
ADVANCE/DEFEND → 损失超阈值 → RETREAT（撤退）
RETREAT → 脱离接触 + 血量恢复 → DEFEND
任意 → 上级 HOLD → HOLD（静默）
```

> **受击面防御**：选择 ADVANCE 的编队也会命令受击严重（血量 < 50%）的成员转 DEFEND，
> 实现「进攻中的局部防御」。

### 火力分配（贪心）

- 每 Tick 统一整理敌接触，**两轮分配**：第一轮保证每目标至少 1 成员覆盖（避免
  部分目标落空）；第二轮补并发到每目标 `MAX_CONCURRENT_FIRE=3`（防过度杀伤）。
- 每个成员最多分配一个目标；选「距目标最近 + 有弹药」的成员。

## 二、炮兵与反炮闭环

### 2.1 曲射火力

- 炮兵单位 `role=ARTILLERY`，不直射，走 `fire_indirect`（弹道解算 + 高抛落点引爆）。
- 编队 AI 统一分派弹药/目标/齐射数；接受两类指令：
  - **友军请求**（装甲/侦察发现目标下单，priority=0）
  - **玩家指令**（叙事层 `STRIKE`，priority=1，**优先级最高**）

### 2.2 反炮循环（开火→暴露→反炮→转移）

```
我方炮兵开火 → 炮口闪光暴露
   → 敌方侦察检测闪光 → 反炮 STRIKE 落我阵地
   → 我方检测来袭曲射弹 → 命令炮位疏散转移（远离落点）
```

- **反炮死循环自然收敛**：反炮有冷却 + 弹药消耗。
- 疏散转移沿「远离威胁落点」方向机动，转移后 10s 冷却防重复触发。

### 2.3 战术运用

- 炮兵编队 `comm < 0.5` → 不收指令（指挥链断裂）。
- 玩家 `STRIKE` 直达中央阵营炮兵 AI；敌方炮兵同样会对我方闪光反炮——**打完就换阵地**。

## 三、通信簇与战争迷雾

- 单位/编队各有 `comm`（0~1）。`comm ≥ 0.5` 的己方编队构成**中央集群**（大面板可见、
  可协同、可收玩家指令）。
- `comm < 0.5` → 与中央断开，**独立建网**：内部仍可自主协同，但大面板不可见。
- 数据共享门控：
  - 敌接触表：同簇内广播。
  - 编队指令下达：编队 `comm` 高。
  - 跨编队协同（装甲叫炮兵）：同簇 + 双方 `comm` 高。
  - 玩家指令：只到达中央集群。

> Phase 6c 用 `comm` 标量 + 阵营分组简化；Phase 8 换 networkx 连通分量 + Twin 同步。

## 四、电子战：RWR 告警与规避

| 告警 | 规避行为 |
|------|----------|
| 敌雷达照射（平台雷达 / 主动导引头） | 开 ECM + 机动规避 + 烟雾 |
| 敌激光照射（SAL 来袭前兆） | 紧急机动 + 抛烟雾遮蔽光斑 |
| 导弹来袭（制导弹丸接近） | 急转 + 抛诱饵（flare/chaff）+ ECM |

- **RWR** 复用 ESM 被动接收，判定「我被照射了吗」→ 发 `rwr_warning`。
- **诱饵** = 短寿命高功率 emitter（`EMITTER_KIND_DECOY=5`），恒指数衰减后失活归还。
- 规避沿「远离告警方向」机动，ECM 提升压制敌方射频导引头检测。

## 五、射界规避与队形

- **队形保持**：机动编队成员按槽位**楔形展开**（slot 0 锚点，其余左右交替向后），
  复用 `FormationResolver` 保证不重叠。
- **射界规避**：发现敌方直射火力（坦克/攻顶 ATGM 发射器）射界锥（朝向 ±30° × 射程）
  → 命令成员沿敌朝向垂直方向绕出，退出有效射程。

## 六、爆炸/毁伤提交池

- 所有弹药伤害模型（细锥/锥形/球形/破片锥）先 `submit_damage` 进池，Tick 末统一
  Numba 批量结算——既加速，又为渲染提供统一爆炸数据源（`drain_explosions()`）。
