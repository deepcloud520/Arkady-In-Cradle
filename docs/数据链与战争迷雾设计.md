一、范式定义：物理世界 vs 认知孪生
概念	物理世界（The Truth）	认知孪生（The COP / Twin）
内容	所有单位的真实位置、状态、血量、弹药	玩家（指挥官）当前相信的位置、状态、血量
更新者	模拟引擎（碰撞、移动、后勤）	传感器融合 + 情报报告 + 时间衰减
玩家可见性	永远不可直接见（上帝视角被封印）	这是玩家在屏幕上看到的唯一内容
数据存储	real_pos, real_health, real_status	twin_pos, twin_health, twin_status
关键法则：渲染管线只绘制 Twin 数据，永远不直接绘制 Real 数据。玩家永远在“看地图上的标记”，而不是“看物理世界的真相”。

2. 时间衰减与航迹外推（当观测丢失时）
如果某个单位超过 N 秒未被观测到，twin 不再可靠：

```python
def decay_twin_world():
    for i in range(n_active):
        elapsed = current_tick - twin_timestamp[i]
        if elapsed > 10:  # 10秒未更新
            # 置信度指数衰减
            twin_confidence[i] *= 0.99
            
            # 如果置信度低于阈值，降级状态

```
3. 友军报告注入（叙事/通讯延迟）
当友军单位通过无线电报告“我看到一辆T-80在坐标XXX”时：

```python
def inject_friendly_report(unit_id, reported_pos, reported_status, delay_ticks):
    # 延迟 N 个 Tick 后生效（模拟通讯延迟）
    schedule_event(delay_ticks, lambda: 
        twin_pos[unit_id] = reported_pos
        twin_status[unit_id] = reported_status
        twin_confidence[unit_id] = 0.6  # 目视报告可信度中等
    )
```
四、渲染层的“孪生消费”
你的 Renderer 不再读取 real_* 数组，而是完全基于 twin_* 数组绘制：

孪生状态	渲染表现
status = ACTIVE, confidence > 0.8	绘制完整模型 + 高亮光环（精准）
status = ACTIVE, confidence < 0.5	绘制半透明模型 + 抖动偏移（模糊接触）
status = UNKNOWN	绘制巨大的“?”标记（在最后已知位置）
status = KIA, confidence > 0.9	绘制静态残骸模型（带红叉标记）
status = MIA	绘制灰色轮廓 + 闪烁边框（信号丢失）
最重要的视觉反馈：当 twin_pos 与 real_pos 偏差较大时（说明玩家的认知落后于现实），在 UI 上显示“情报偏差警告”，增加心理恐怖感。

五、与“地雷命中”场景的完美契合
现在看你的原始场景——坦克被地雷击中——在这个双重世界模型下变得极其自然：

Tick 0（物理命中）：

real_status 变为 KIA（物理世界击毁）。

但 twin_status 保持不变（仍然是 ACTIVE，因为还没人报告它被炸了）。

Tick + 5（通讯中断）：

C2 系统发现该单位信号丢失。

twin_status 变为 MIA，玩家在地图上看到灰色的“?”闪烁。

Tick + 30（无人机侦察到达）：

无人机飞过该区域，发现残骸。

detection 模块触发，执行 on_unit_detected()。

twin_status 变为 KIA，twin_confidence 设为 0.95。

玩家看到“?”变成红色的“✕”残骸标记，同时叙事层弹出报告：“无人机确认击毁。”

六、性能与架构优势
零 GPU 额外开销：渲染层只是切换了读取的数组指针，Draw Call 数量不变。

CPU 开销可控：更新孪生世界只是遍历 2000 个单位做浮点运算，耗时 < 0.1ms。

与“主题商店”兼容：构成主义风格下，孪生误差表现为虚线框 + 测量标尺；日系风格下，孪生误差表现为半透明虚影 + 马赛克粒子。底层数据流完全一致。

物理世界（Real）是不可见的底层真相，由模拟引擎维护。认知孪生（Twin）是玩家看到的唯一现实，由传感器融合、时间衰减和叙事注入共同驱动。地形是已知的背景板，永远不变。战争迷雾的本质，是 Twin 与 Real 之间的“置信度缺口”。
